# Compatibility with Other Mods
## Cadmus
This mod works seamlessly with [Cadmus](https://modrinth.com/mod/cadmus).

If Cadmus is installed, the game will register a new [configuration file](cadmus.md). The key feature is
protecting spawn chunks by default. Additionally, the command `/cadmus skyblockbuilder protectSpawn` allows claiming
spawn chunks after world creation.

This is especially useful for modpacks where spawn protection is disabled by default, but the server owner wants to
enforce it.

## Curios
This mod is compatible with [Curios](https://modrinth.com/mod/curios). This means that items from the Curios inventory
will be dropped when leaving a team, provided that the [config](../packdev/config/inventory.md#dropping-inventory) is
also enabled.

## Heracles
This mod is fully compatible with [Heracles](https://modrinth.com/mod/heracles).

A new task type for [spreads](../packdev/packdev.md#configuring-templates) will be added when Heracles is installed.
Additionally, a new [configuration file](heracles.md) is registered. You can combine multiple spreads in
the GUI using the `|` separator.

For example, if you want to combine multiple spreads, you could use the following as input for the GUI:

`water_cave|water_cave_birch|water_cave_dark_oak|water_cave_desert|water_cave_jungle|water_cave_spruce|water_cave_swamp`

## MineMention
This mod is compatible with [MineMention](https://modrinth.com/mod/minemention). To write in the team's chat, you can
use `skyblockbuilder:sky_team` in the MineMention config file. This should look like this:

```json title="config/minemention.json5"
{
  "mentions": {
    "everyone": "minemention:everyone",
    "here": "minemention:here",
    "team": "skyblockbuilder:sky_team"
  }
}
```

## [Sky GUIs](../../sky-guis)
Tired of managing everything with commands? [Sky GUIs](https://modrinth.com/mod/sky-guis) is here to help!

This mod provides user-friendly graphical interfaces for tasks like creating teams, joining teams, and inviting other players. Say goodbye to complicated commands and enjoy a smoother experience.
