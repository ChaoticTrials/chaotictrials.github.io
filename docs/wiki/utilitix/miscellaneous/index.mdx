# Miscellaneous
## Armed Stand
The **Armor Stand with Arms** includes arms. The pose of the armor stand can be changed by shift-right-clicking it with
flint and configured in the settings.

## Decoration
### Stone Wall
Just a **Stone Wall** because vanilla doesn't add one.

## Map Printing
Use the command `/utilitix print_map [scale]` to save the map in your hand as a PNG. With scale `1`, the map will be
128x128 pixels. In the client config, you can adjust the default scale. However, you can always override this config
option in the command itself. If you choose a too high scale, your graphics card may not be able to render the map.
