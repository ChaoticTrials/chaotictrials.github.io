# Items
## Ancient Compass
The Ancient Compass points to the nearest Ancient City. It can be found in a spawner room chest with a 3.125% chance.

## Diamond Shears
**Diamond Shears** function similarly to vanilla shears but are crafted using diamonds and boast durability of 1486.

## Bells
### Hand Bell
The **Hand Bell** is an item that, when rung, highlights raiders similarly to a normal bell in Minecraft. This makes it
useful for locating and dealing with raiders during a raid. You can increase the range with
the [Bell Range](#bell-range-enchantment) enchantment.

### Mob Bell
The **Mob Bell** can be bound to a mob by shift-right-clicking on it. When rung, it highlights mobs of the same type as
the bound mob, making it easier to locate specific types of mobs. You can increase the range with
the [Bell Range](#bell-range-enchantment) enchantment.

### Bell Range Enchantment
Increases the notification and glow range of the [Hand Bell](#hand-bell) and [Mob Bell](#mob-bell) by 25% per level.
By default, the glow radius without Bell Range is 36 and the notification radius is 24 blocks. This increases to:
- **Level 1**: 45 and 30 blocks
- **Level 2**: 54 and 36 blocks
- **Level 3**: 63 and 42 blocks

## Mob Yoinker
The **Mob Yoinker** is a cage for storing mobs. The Yoinker requires your experience points to store a mob. It requires
one xp point for each health point of the mob. If you're only missing one xp point, consider hitting the mob once with
your fist. However, if the common config value says that levels will be used instead of xp points, you need the
experience levels instead of points.

## Tiny Coal
The **Tiny Coal** is a small piece of coal that smelts exactly one item. It is efficient for single-item smelting tasks
without wasting excess fuel.

## Quiver
The **Quiver** is a simple item that can be used to store arrows. The quiver can be enchanted with **Infinity**. That
way, you can have **Mending** on your bow and still have the benefits of **Infinity**. Without that enchantment, the
quiver is still be useful because it stores up to 9 stacks of arrows in a single inventory slot.

:::info
Infinity can only be applied in an Anvil.
:::
