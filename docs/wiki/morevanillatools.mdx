## Obsidian Pickaxe
The **Obsidian Pickaxe** excels at breaking Obsidian blocks more efficiently. If you frequently need to mine Obsidian,
using Obsidian tools is highly recommended.

## Slime Tools
**Slime Tools** naturally cause knockback when used. Be mindful of this when hitting an object or enemy.
