# Customization
*The settings on this page can be configured in `config/skyblockbuilder/customization.json5`.*

## Show Team Names in Tab List
Enable this option to display team names in the server's tab list.  
![](/img/projects/skyblock-builder/features/tab_list.png)

## Automatically Delete Teams
When the last player leaves a team, the team will be automatically deleted.  
The team’s island and all its blocks will remain unchanged, but this position will not be assigned to any new team. Only the team itself is removed.

## Allow Unsafe Profile Names
Enable this option if you encounter issues with game profiles related to profile names.
