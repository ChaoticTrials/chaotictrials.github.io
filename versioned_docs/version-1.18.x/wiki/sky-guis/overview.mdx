# Overview
<ToggleImage src="/img/projects/sky-guis/overview.png" alt="Overview GUI" />

You can access this screen by using the key `L` in-game. Alternatively, you can use the command `/skyblock gui`.

This screen lists all available teams. Teams with no members are highlighted in red, while teams with members appear in
green.

Hover over a team name to view additional details such as the creation date, last updated time, and the current number
of members. If advanced tooltips are enabled (via **F3 + H**), the team ID will also be displayed.

At the bottom of the screen, you'll find a button to [create a new team](create-team.mdx). If you're already part of a
team, the button will instead display your team name.

Click on any team name to interact with [other teams](other-team.mdx) or access your [team settings](own-team.mdx) if the
team is yours.
