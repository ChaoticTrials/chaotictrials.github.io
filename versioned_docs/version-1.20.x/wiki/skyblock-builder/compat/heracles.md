# Heracles
*Configuration settings on this page are found in the file: `config/skyblockbuilder/heracles.json5` when the
[Heracles 🔗](https://modrinth.com/mod/heracles) mod is installed.*

## Reset Quest Progress
When enabled, this setting resets a player's quest progress if they leave a team, whether by being kicked or leaving 
voluntarily.  

:::note
This does not affect players with a permission level of 2 or higher.
:::

## Skip Non-Existent Spreads
If a player is not part of a team or the team lacks a spread, enabling this option allows the related tasks to be 
completed without requiring the player to visit these spreads.
