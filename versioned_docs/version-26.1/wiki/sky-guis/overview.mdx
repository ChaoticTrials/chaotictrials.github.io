# Overview
<ToggleImage src="/img/projects/sky-guis/1.20/overview.png" alt="Overview GUI" />

You can access this screen by using the key `.` in-game. Alternatively, you can use the command `/skyblock gui` or
`/sky gui`.

This screen lists all available teams. Teams with no members are highlighted in red, while teams with members appear in
green.

Hover over a team name to view additional details such as the creation date, last updated time, and the current number
of members. If advanced tooltips are enabled (via **F3 + H**), the team ID will also be displayed.

At the bottom of the screen, you'll find a button to [create a new team](create-team.mdx). If you're already part of a
team, the button will instead display your team name.

If you've been invited to a team and haven't joined one yet, a **Review Invites** button appears next to it, with a
badge showing how many invitations are waiting. The badge counts up to five and switches to a "more" icon beyond that.
Once you're in a team, neither the button nor the badge is shown.

Below the screen, you'll find a button to teleport to the World Spawn. If you're part of a team, an additional button
will appear to teleport you back home.

Next to the screen, you'll find a collapsible filter panel. Use it to enable or disable filters for specific teams.
By default, empty teams are hidden and sorted alphabetically. You can change the sorting to **alphabetical**, **creation
date**, **last modified date**, or **member count**, in either ascending or descending order.

Click on any team name to interact with [other teams](other-team.mdx) or access your [team settings](own-team.mdx) if the
team is yours.
