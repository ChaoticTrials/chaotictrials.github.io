# Other Team

<ToggleImage src="/img/projects/sky-guis/1.20/other_team.png" alt="Other Team GUI" />

This interface allows you to request to join or visit another team if enabled in the settings. Each option (joining or visiting) can be enabled or disabled by the team itself.

To use these features, they must first be activated in the Skyblock Builder's configuration settings.
