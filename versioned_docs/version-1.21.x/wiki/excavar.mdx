Mining in batches is possible and handy in some cases. This mod allows it!

---

## How to Use
1. Select the correct tool (can be disabled in config).
2. Press the key for mining multiple blocks (default: left `Alt`).
3. Hold the key and mine the targeted blocks.

The key is called `Multimine` in the category `Excavar`.

## Additional Features
As shown in this image, you'll see a preview of targeted blocks. This highlighting may be incorrect if you have an
enchantment like Unbreaking on your tool.

<ToggleImage src="/img/projects/excavar/highlighting.png" />

Additionally, you see the "Selected shape" is set to "Shapeless". Shapes can be added by other mods. Built-in the mod,
there are two different shapes:

- Shapeless - `excavar:shapeless`
    - Searches for any block around it.
- Tunnel - `excavar:tunnel`
    - Searches only in the direction you're facing the block at.
- 3x3 Tunnel - `excavar:big_tunnel`
    - Searches only in the direction you're facing the block at and in all eight blocks around it.

Switching the shape can be done by holding the Multimine button (default: left `Alt`) while sneaking and scrolling.

### Forbidden Blocks
The `excavar:forbidden_blocks` tag is used to specify blocks that Excavar will ignore. This means players cannot multi-mine blocks with this tag.

If the `invertForbiddenTag` option is enabled, only the blocks with this tag will be mineable.

## Adding compatability
For adding compatibility with other mods, Excavar adds these item tags:
- `#excavar:axes` - contains `#minecraft:axes`, `#c:tools/aiots`, and `#c:tools/paxels`
- `#excavar:hoes` - contains `#minecraft:hoes`, `#c:tools/aiots`
- `#excavar:pickaxes` - contains `#minecraft:pickaxes`, `#c:tools/aiots`, and `#c:tools/paxels`
- `#excavar:shovels` - contains `#minecraft:shovels`, `#c:tools/aiots`, and `#c:tools/paxels`
- `#excavar:swords` - contains `#minecraft:swords`, `#c:tools/aiots`

For adding compatibility as **pack developer**, you can use these Excavar tags to add more tools without breaking recipes
that rely on the vanilla tool tags.

As **mod developer**, you should add your tools to the vanilla tool tags, or the corresponding `c` (common) tags.
