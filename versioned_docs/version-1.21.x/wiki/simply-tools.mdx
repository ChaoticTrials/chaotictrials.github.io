This mod extends the vanilla Minecraft experience by introducing new tools such as hammers and excavators that allow for
mining in a **3x3 area**, saving you time and effort when mining or excavating.

---

## Tools
**Hammers**
- Perfect for breaking blocks like **Stone**, these tools work in a **3x3 area** to make mining faster and more efficient.

**Excavators**
- Perfect for breaking blocks like **Dirt**, these tools work in a **3x3 area** to make mining faster and more efficient.

### Obsidian Hammer
The **Obsidian Hammer** excels at breaking Obsidian blocks more efficiently. If you frequently need to mine Obsidian,
using Obsidian tools is highly recommended.

## Enchantments
**Power of the Depth**
- This enchantment increases your mining depth by 1 for each level, up to a maximum level of **3**. At the highest
level, it allows you to mine a 3x4x3 block area.

:::info
You can disable this enchantment for Villagers, preventing them from offering it as an enchanted book in trades.
:::

## Configuration
The mod allows you to tweak its behavior by changing some configuration options. Below is the list of configurable
settings:

| **Key**                          | **Default Value** | **Description**                                                    |
|----------------------------------|-------------------|--------------------------------------------------------------------|
| `vanillaOnly`                    | `false`           | If set to `true`, disables compatibility features with other mods. |
| `durabilityModifier`             | `1.5`             | Multiplier for tool durability                                     |
